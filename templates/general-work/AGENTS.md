## 项目目录地图

- 项目根目录：放任务级 Agent 工作约定、全局说明和配置。
- `doc/requirements/`：存放跨任务维护的任务需求、已确认规则和验收标准；涉及任务目标或规则时优先读取这里。
- `doc/design/`：存放跨任务维护的已确认方案、流程和设计资料。
- `doc/tasks/`：存放用户要求新增的任务；每个任务的文件夹集中存放该任务的需求、设计和调研文件。
- `doc/decisions/`：存放任务各模块的实现决策；根索引文件为 `doc/decisions/index.md`。
- `doc/implementation/`：存放任务当前实现模块的分层地图；根索引文件为 `doc/implementation/index.md`。
- `doc/memory.md`：存放用户明确要求记录且经用户批准的分类记忆。
- `doc/reviews/archive/YYYY-MM/`：按月份归档阶段性评审、调研和其他中间材料，特别是无需长期维护的材料。此处内容仅供参考，不作为当前任务规则的唯一来源。
- `assets/requirements/`：存放需求和设计文档引用的截图、图片等素材。

## 工作规则

- 除非用户明确要求，禁止创建、委派或使用子智能体；不得仅因任务可并行而主动创建子智能体。
- Git 提交说明使用简短、准确的中文。
- 文件或资料不知道该放在哪个目录时，先询问用户，不要自行猜测或创建新目录。
- 当用户明确要求“记下”或“记住”某项内容时，先检查 `doc/memory.md`，整理拟记录的内容并确定所属类别，然后向用户展示拟写入内容并征求批准；获得批准后才能写入。按类别维护记忆，不要直接在文件末尾追加：若内容已存在或用户是在修正旧记忆，应更新或合并对应条目；保留其他仍有效的记忆，仅在确有需要时新增类别。
- 所有任务汇报，问题的回答默认使用i-have-adhd技能

## 任务规则

- 当用户要求新增项目任务时，先查看 `doc/tasks/任务看板.md`：进行中任务超过 3 个时，询问是否有任务已终止；存在已完成但未归档的任务时，提醒用户归档。
- 创建项目任务时，在 `doc/tasks/` 下新建以任务名称命名的文件夹，并在该文件夹中建立临时文件夹来存放完成该任务时生成的临时文件，该任务的最终产出文件（如果有）直接存放到该任务文件夹中。
- 新任务及状态变化须同步到 `doc/tasks/任务看板.md`。
- 用户确认归档任务后，将 `doc/tasks/<任务名>/` 移至 `doc/tasks/archive/YYYY-MM/<任务名>/`，并将该任务移至 `doc/tasks/任务看板.md` 的“已归档”分类。

## 项目决策记录

- 开始涉及项目代码、设计或文档变更的任务前，先读取 `doc/decisions/index.md`，再根据索引按需读取相关模块的决策文件。
- 决策按模块分层组织。根据当前项目结构、已有决策和本次任务确定模块划分与层级；根索引维护模块及其决策位置。
- 新增或更新决策时，先扫描根索引定位模块，再将内容写入该模块的恰当位置；不得直接追加到文件末尾。
- 每项决策须是可约束后续同类开发的长期模块规则；单次任务、用例或文件的具体实现，不作为决策。
- 每项决策包含状态（已确认、暂定或已废弃）、日期、决策内容、理由或约束，以及关联文件（如有）。“关联文件”是该决策直接依据、约束、修改或影响的需求文档、设计文档、源代码、配置或测试文件的项目相对路径；尚无具体文件时可省略。
- 新决策与已有决策明确冲突时，暂停写入，说明旧决策、新提议及影响，提出建议并请求用户指示；信息不完整但未明确冲突时，标记为“暂定”并说明待确认事项。
- 某模块的决策内容超过 80 行时，将其详细决策拆分到独立 Markdown 文件；根索引保留简短结论、相对路径和具体标题位置。
- 被替代的历史决策标记为“已废弃”，并注明或链接替代决策。

## 实现模块地图

- 开始涉及任务代码、设计或文档变更的任务前，先读取 `doc/implementation/index.md`，再按需读取相关模块的说明文件。
- 实现模块是指具有独立且长期职责的一组实现能力；可对应多个代码目录，不要求与代码目录一一对应。
- `doc/implementation/` 记录任务当前已实现的主要模块，根索引为 `doc/implementation/index.md`。
- 直接相关的决策与实现模块双向链接；没有相关决策时不建立链接。
- 任务完成并验证后，如实际改动新增、调整或移除了长期实现模块，Agent 应在任务汇报中提出包含模块、主要实现位置和关联决策（如有）的更新建议；仅在用户批准后更新实现模块地图及相关决策链接，局部且不改变模块职责的修改无需建议更新。
